# Churrasco de Formatura do JP

Site de confirmação de presença (RSVP) do churrasco de formatura do JP — sábado, 12/12, a partir das 13h, na churrasqueira da Rua Cesar Lattes, 560 (Barra da Tijuca).

- `index.html` — página dos convidados: nome → vai/não vai → acompanhantes → bebidas.
- `painel.html` — placar ao vivo das respostas (pede a senha do painel, atualiza a cada 5 s).
- `config.js` — URL e chave pública do Supabase.
- `supabase/schema.sql` — tabela, regras de acesso e função do painel.

Hospedado no GitHub Pages; os dados ficam no Supabase (o público só consegue inserir respostas).
